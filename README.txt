Arrow Challenge — Flutter Puzzle Game
=====================================

Unzip this archive. The Flutter project is NOT nested.

  Arrow-Challenge/
    Documentation/     Open index.html in a browser
    Source-Code/       Flutter project root (pubspec.yaml is here)

Get started:

  cd Source-Code
  flutter pub get
  flutter run

Do not look for source-code/app/... or a second arrow_challenge_game folder.
